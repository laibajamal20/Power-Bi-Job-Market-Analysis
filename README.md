# Power BI Job Market Analysis Dashboard



## Overview

An interactive Power BI dashboard that explores job market trends, salary distributions, experience levels, and employment settings.



## Dashboard Pages



### Page 1: Job Market Overview

- Key job market KPIs

- Job distribution by experience level and job category

- Average salary analysis

- Job distribution by work setting



### Page 2: Salary \& Employment Insights

- Median and minimum salary KPIs

- Full-time employment percentage

- Average salary by job category

- Average salary by experience level

- Average salary by work setting

- Employment-type distribution



## Tools & Technologies

- Microsoft Power BI Desktop

- Power Query for data preparation

- DAX for measures and calculations

- Data visualization and exploratory data analysis



## Key Skills Demonstrated

- Data cleaning and transformation

- KPI creation

- Salary and employment analysis

- Interactive report design using slicers

- Business-oriented data visualization



## Project Files

- `.pbix` report file

- Dashboard screenshots




## How to Use

Download the Power BI report file and open it using Microsoft Power BI Desktop.



## Note

This project analyzes the dataset used in the report. Findings reflect the available data and should not automatically be interpreted as representative of the entire job market.
